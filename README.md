# pycom — Python 학습실 v1.1.0 수업용 배포판

학생 접속 주소: <https://ljyoon1104-code.github.io/pycom/>

브라우저에서 실행되는 수업용 Python 학습 환경입니다. 회원가입과 Python 설치가 필요하지 않으며, 학생 코드는 서버로 전송되지 않습니다.
화면에 표시되는 배포판 버전은 `package.json`의 `version`을 빌드할 때 주입해 한 곳에서 관리합니다.

## 학생 사용법

1. 링크 또는 QR 코드로 [학습 앱](https://ljyoon1104-code.github.io/pycom/)에 접속합니다.
2. Python 설치 없이 코드를 작성합니다.
3. **실행** 버튼으로 결과를 확인합니다.
4. `input()` 입력창이 나타나면 값을 입력합니다.
5. 파일은 **저장** 버튼을 눌렀을 때만 저장됩니다.
6. 한 파일은 **내보내기**, 저장된 파일 전체는 **전체 백업**으로 보관합니다.

처음 접속하면 시작 안내가 표시됩니다. **도움말**에서는 사용법과 데이터 보관 주의를 다시 확인할 수 있고, **예제**에서는 출력부터 교육용 turtle까지 자체 제작 예제 11개를 불러올 수 있습니다. 예제도 자동 저장되지 않습니다.

`.py`, `.txt`, `.csv` 파일은 현재 기기의 브라우저 저장소에 보관됩니다. 기기를 바꾸려면 **전체 백업**으로 만든 `.pylab-backup.json` 파일을 새 기기에서 **전체 복원**하세요. 자동 저장은 하지 않습니다.

## 간편 실행

1. `앱 실행하기.cmd`를 더블클릭합니다.
2. 브라우저가 자동으로 열릴 때까지 기다립니다.
3. 앱을 종료하려면 실행 중인 검은색 창을 닫습니다.

휴대폰·태블릿에서는 실행 창에 표시된 `Network` 주소를 입력해 접속할 수 있습니다. 휴대폰·태블릿과 PC는 같은 Wi-Fi에 연결되어 있어야 합니다.

## 웹 앱과 오프라인 사용

일반 웹 주소로 접속해도 모든 기능을 사용할 수 있습니다. 처음 온라인으로 접속한 뒤에는 브라우저 메뉴의 **홈 화면에 추가** 또는 **앱 설치**를 선택해 앱처럼 열 수 있습니다. iPhone·iPad에서는 공유 버튼에서 **홈 화면에 추가**를 선택하세요.

## 교사용 안내

- 회원가입과 Python 설치가 필요하지 않습니다.
- 학생 코드와 파일은 서버로 전송되지 않고 각 기기의 브라우저 IndexedDB에 저장됩니다.
- 브라우저 데이터를 삭제하면 학생 파일도 삭제될 수 있습니다. 앱 업데이트와 Service Worker 캐시 정리는 학생 파일을 삭제하지 않습니다.
- 자동 저장하지 않습니다. 수업 종료 전 **저장**과 **전체 백업**을 안내해 주세요.
- 다른 기기에서는 전체 백업 JSON 한 개를 **전체 복원**해 저장 파일을 옮길 수 있습니다.
- 최초 온라인 접속 뒤에는 앱 셸, 편집기, 인터프리터 Worker가 캐시되어 오프라인에서도 사용할 수 있습니다.
- 변수와 기본 자료형, 조건문·반복문, 컬렉션, 함수, 클래스 기본 기능, 파일 입출력, 예외 처리, `random`, `datetime.date`, 교육용 `turtle`을 지원합니다.
- 외부 패키지와 고급 Python 전체는 지원하지 않습니다.
- EUC-KR 텍스트와 CSV는 읽기 전용입니다. 쓰기와 내보내기는 UTF-8을 사용합니다.
- 새 버전 알림에서 **업데이트**를 누르면 수정 중인 문서의 저장 여부를 먼저 확인합니다.
- 학생 접속 주소는 <https://ljyoon1104-code.github.io/pycom/> 입니다.

## 전체 백업·복원과 현장 진단 (15단계)

- **전체 백업**은 IndexedDB에 명시적으로 저장된 `.py`, `.txt`, `.csv` 파일만 UTF-8 JSON으로 내려받습니다. 현재 편집기의 미저장 내용, 실행 출력과 입력값, 오류 위치, 앱 설정, 브라우저 정보, Service Worker 캐시는 포함하지 않습니다.
- 수정 중인 문서가 있으면 `현재 문서 저장 후 백업 / 저장하지 않은 상태로 백업 / 취소`를 먼저 선택합니다. 앱이 임의로 자동 저장하지 않습니다.
- **전체 복원**은 백업 형식과 버전, 모든 파일 이름·내용·인코딩·시각·크기·중복 여부를 저장 전에 검사합니다. 같은 이름은 한 작업 전체에 대해 `기존 파일 유지 / 백업 파일로 덮어쓰기 / 백업 파일 이름 변경 / 취소` 중 하나를 선택합니다.
- 이름 변경은 `main (복원 1).py`처럼 확장자 앞에 번호를 붙입니다. 복원은 IndexedDB의 단일 트랜잭션으로 처리하므로 실패하면 기존 파일 전체가 유지됩니다.
- 현재 지원하는 백업 형식은 버전 1입니다. 더 새로운 형식은 앱 업데이트를 안내하며 거부하고, 버전 1의 누락된 선택 메타데이터에는 안전한 기본값을 적용합니다.
- **도움말**에는 앱 파일의 근사 사용량과 브라우저 저장 공간 정보가 표시됩니다. **환경 정보 확인**은 앱/백업 버전, 브라우저 제품과 주 버전, OS 계열, 온라인·PWA·Service Worker 상태, 파일 수와 근사 크기, 화면 크기, 마지막 실행 결과 범주만 미리 보여 준 뒤 복사합니다.
- 환경 정보에는 학생 코드와 파일 내용·파일명·입력값, 전체 User-Agent, 로컬 경로와 IP, 토큰·쿠키가 포함되지 않습니다.
- 백업 JSON에는 학생 코드와 파일 내용이 들어 있습니다. 필요한 사람에게만 전달하고, 공용 PC에서는 내려받은 백업 파일을 수업 뒤 안전하게 정리하세요.

## 기본 표준 라이브러리 (11단계)

- 허용된 모듈은 앱에 포함된 `random`, `datetime`뿐입니다. 일반 사용자 모듈·외부 패키지·네트워크 import는 지원하지 않습니다.
- `import random as rnd`, `import datetime`, `from datetime import date as Date`를 사용할 수 있습니다. 지원하지 않는 가져오기는 `ImportError`로 처리합니다.
- `random.seed`, `randint`, `randrange`, `choice`, `sample`을 지원합니다. 실행별 Mulberry32 상태를 사용하며 같은 시드·호출 순서는 재현됩니다. CPython과 시드별 난수열이 같다는 의미는 아니며 보안용 난수가 아닙니다.
- `sample`은 원본 위치를 중복 선택하지 않는 비복원 추출이며 원본을 변경하지 않습니다. Python처럼 원본에 같은 값이 여러 번 들어 있다면 서로 다른 위치의 같은 값이 선택될 수 있습니다. 한 번에 최대 10000개를 선택합니다.
- `date(year, month, day)`, `date.today()`, 연·월·일 속성, 문자열 출력, 날짜 비교를 지원합니다. 오늘은 학생 기기의 현지 날짜입니다. 테스트는 VM의 시계 공급자를 주입하며 시스템 시간을 바꾸지 않습니다.
- 두 모듈은 Worker 번들에 포함되어 오프라인에서도 실행됩니다. 모듈·날짜 속성은 읽기 전용이며 전체 random API, datetime.datetime, 시간대·날짜 간격은 제외합니다.

## EUC-KR 텍스트 가져오기 (12단계)

- TXT·CSV 파일 가져오기에서 **자동 감지 / UTF-8 / EUC-KR**을 선택할 수 있습니다. 자동 감지는 UTF-8 BOM, 엄격한 UTF-8, EUC-KR 순서로 판별합니다.
- `open(..., encoding="euc-kr")`와 `cp949`, `euc_kr`, 대소문자 별칭으로 가져온 한글 텍스트를 읽을 수 있습니다. 앱 안에서는 안전하게 디코딩한 Unicode 텍스트를 사용합니다.
- EUC-KR은 읽기만 지원합니다. `w`·`a` 모드와 내보내기는 UTF-8만 지원하며, EUC-KR로 쓴 것처럼 표시하지 않습니다.
- 파일명·내용·가져오기 인코딩·원본 바이트 크기·수정 시각은 현재 기기의 IndexedDB에 저장됩니다. 기존 파일은 삭제하지 않고 UTF-8 메타데이터를 보충합니다.

## 교육용 turtle 그래픽 (13단계)

- `import turtle`, `turtle.Turtle()`, `turtle.done()`과 `turtle.mainloop()`를 지원합니다. 실행 결과에서 **그래픽** 탭이 자동으로 열리고, 텍스트 출력은 **텍스트** 탭에서 함께 확인할 수 있습니다.
- 이동·회전: `forward`/`fd`, `backward`/`back`/`bk`, `right`/`rt`, `left`/`lt`, `goto`/`setposition`/`setpos`, `home`, `setheading`/`seth`를 지원합니다.
- 펜·상태: `penup`/`up`/`pu`, `pendown`/`down`/`pd`, `pencolor`, `color`, `pensize`/`width`, `clear`, `reset`, `hideturtle`, `showturtle`, `speed`, 좌표·방향 조회를 지원합니다. 색상은 기본 색상 이름과 `#RRGGBB`만 허용합니다.
- 그래픽 명령은 Worker가 Canvas에 직접 접근하지 않고 메인 화면으로 전달합니다. 한 실행은 최대 5000개 명령으로 제한되며, 제한 초과는 `except`로 우회할 수 없습니다.
- `circle`, `dot`, 채우기, 키보드·마우스 이벤트, 애니메이션 콜백, 이미지 도형, 다중 화면과 전체 turtle 표준 라이브러리는 지원하지 않습니다.

API 의미 참고: [Python random](https://docs.python.org/3/library/random.html), [Python date](https://docs.python.org/3/library/datetime.html#date-objects).

```powershell
npm test
npm run build
npm run preview
```

수업용 브라우저 회귀 검사는 프로덕션 미리보기 서버를 연 상태에서 `npm run verify:classroom`으로 실행합니다. 결과와 스크린샷은 커밋되지 않는 `artifacts/stage14`에 저장됩니다.
