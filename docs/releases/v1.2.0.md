# Python 학습실 v1.2.0

[교과서 예제 열기](https://ljyoon1104-code.github.io/pycom/#/examples) · [학습실 편집기](https://ljyoon1104-code.github.io/pycom/)

## 새 기능

- 120–153쪽의 학습 개념과 연계한 자체 제작 예제 56개를 쪽 번호·제목·문법·주제로 검색합니다. 기존 기초 예제 11개도 유지합니다.
- 읽기 전용 코드 뷰어에서 예제를 임시 실행합니다. 입력, 파일 입출력, random, datetime.date, turtle Canvas를 사용할 수 있습니다.
- 학생의 현재 코드·수정 표시·출력·저장 파일과 예제 Worker/임시 파일 공간을 분리했습니다. 예제 실행 자체는 학생 파일을 읽거나 변경하지 않습니다.
- 편집기로 가져올 때 저장·저장하지 않음·취소를 선택할 수 있습니다. 데이터는 코드만/코드와 데이터/취소 및 기존 유지·덮어쓰기·이름 변경 정책을 제공합니다. 코드는 자동 저장하지 않습니다.
- 해시 기반 예제 직접 링크를 복사해 학생에게 전달할 수 있습니다. 직접 접속과 새로고침을 지원합니다.
- 최초 온라인 접속 후 목록·검색·예제 실행을 오프라인에서도 사용할 수 있습니다.

## 검증과 콘텐츠

- 자동 테스트 473개 통과(기존 319개 + 신규 154개), 등록된 전체 67개 예제 실제 VM 실행 완료.
- 5개 화면 크기, 실제 입력·CSV·turtle, 임시 실행 격리, 오프라인과 백업·복원 회귀 검증.
- 원본 오류 6개는 수정 이유와 실행 가능한 자체 제작 예제로 안내합니다.
- 교과서 원문·이미지·독점 CSV를 재배포하지 않습니다. 쪽 번호와 개념만 연계하고 코드·설명·소량 데이터를 새로 작성했습니다.
- 제출·채점·회원가입·추적 기능을 추가하지 않았습니다. 학생 코드·입력·검색어는 서버로 전송되지 않습니다.

## 제한

전체 Python이나 외부 라이브러리를 지원하는 제품은 아닙니다. 기존 인터프리터 범위를 유지하며 `for … else`, 고급 turtle, EUC-KR 쓰기 등은 지원하지 않습니다. 기존 중첩 첨자 복합 대입 오류와 실수 출력 표기 차이도 감사 보고서에 기록했습니다. 예제 데이터 이름을 바꾸어 가져오면 코드의 파일명도 직접 맞춰야 합니다.

설치 파일 첨부 없이 Pages에서 바로 실행하는 웹 배포판입니다. GitHub가 제공하는 Source code ZIP/TAR는 개발용 소스이며 학생 파일 백업이 아닙니다. 기존 v1.0.0/v1.1.0 태그와 Release는 변경하지 않습니다.
