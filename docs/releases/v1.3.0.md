# Python 학습실 v1.3.0

학생 접속: https://ljyoon1104-code.github.io/pycom/

- 여러 문서를 탭으로 열고 전환합니다. 같은 저장 파일을 중복해서 열지 않습니다.
- 탭별 수정 표시, 커서·선택·스크롤과 실행 취소 기록을 유지합니다.
- 현재 탭 저장, 다른 이름 저장, 수정 탭 닫기 전 저장 확인을 제공합니다.
- 업데이트·전체 복원 전 모든 수정 탭을 보호합니다.
- 모바일용 열린 파일 목록과 키보드 탭 이동을 지원합니다.
- 교과서 예제를 기존 문서 위에 덮어쓰지 않고 새 탭으로 가져옵니다.
- 실행·입력·결과에는 실행을 시작한 파일 이름이 표시됩니다. 동시에 여러 프로그램을 실행하지 않습니다.
- 모바일·PWA 오프라인에서 탭 전환과 명시적 저장을 사용할 수 있습니다.
- **자동 저장하지 않습니다.** 저장 버튼을 눌렀을 때만 학생 문서를 저장합니다. 새로고침 시 저장된 탭 목록만 복원하며 미저장 초안과 undo 기록은 복원하지 않습니다.
- 기존 학생 파일과 전체 백업 형식은 유지합니다. 학생 코드와 입력값을 서버로 전송하지 않습니다.

탭 끌기, 고정, 분할 편집기와 여러 창 동기화는 제공하지 않습니다. 기존 Python 문법 지원 범위는 변경하지 않았습니다.
