# Python 학습실 v2.0.0

학생 접속: https://ljyoon1104-code.github.io/pycom/

교육용 Python Core v2.0은 자체 Lexer → Parser → AST → 바이트코드 → VM을 유지한 초·중급 학습용 확장입니다. Python 전체를 구현한 제품은 아닙니다.

- 제어문: `for/while ... else`, 조건 표현식, `is/is not`, 중첩 첨자 복합 대입 보완
- 재귀: 직접·간접 재귀, VM 호출 프레임과 한국어 `RecursionError`
- 예외: `raise`, bare `raise`, `finally`와 모든 제어 이동의 정리; 중지·실행 제한은 잡을 수 없음
- 컬렉션: 집합·딕셔너리/집합 내포, step 슬라이싱, `del`, `assert`, 별표 언패킹
- 함수: `*args/**kwargs`, 람다, 중첩 함수·클로저·`nonlocal`
- 내장 함수: `abs`, `round`, `pow`, `divmod`, 소모형 `enumerate/zip/reversed`, `sorted`, 단락 평가 `any/all`, Unicode와 진수 변환
- 메서드: 안정적인 `list.sort(key/reverse)`, 리스트 편집·복사, 문자열 검색·분리·정렬·판별, 딕셔너리 갱신·복사·기본값
- 클래스: 단일 상속, 부모 생성자·속성·메서드, 사용자 클래스의 `isinstance/issubclass`, 인수 없는 `super()`
- 사용자 모듈: 저장된 `.py`만 검색, 모듈별 전역 환경과 실행당 캐시, 순환 감지, 오류 파일명·줄 표시
- `math`: 허용 목록 상수·기본 함수; 공통 실수 표기로 `1.0`, `-0.0`, `inf`, `nan` 보존
- 예제: 기존 기초 11개와 교과서 연계 56개 유지, 자체 제작 Core 예제 9개 추가
- 기존 학생 파일·탭·백업 형식 유지. 저장 버튼을 눌렀을 때만 저장하며 미저장 다른 탭은 import하지 않음
- 최초 온라인 접속 후 캐시된 앱과 Worker를 사용한 오프라인 실행, 파일 저장·읽기·백업·복원 유지

정수 정밀도는 ±(2⁵³−1) 범위이며 `math.factorial`은 정확한 결과를 위해 18까지 지원합니다. CPython의 숫자·문자열 객체 캐싱이나 모든 부동소수점 repr, 일부 드문 Unicode 변환을 동일하게 복제하지 않습니다. `map` 안의 `input()`은 제외하며 정렬 key 안의 입력 대기·중지는 지원합니다.

계속 제외: 제너레이터/yield, async/await, 데코레이터, 다중 상속, property/descriptor/메타클래스, 패턴 매칭, 패키지·폴더·상대·동적 import, 외부 패키지, 전체 표준 라이브러리, 전체 turtle API, EUC-KR 쓰기.

학생 코드·입력·파일은 서버로 전송되지 않습니다. 외부 Python 실행기, CDN, 채점·제출 기능을 추가하지 않았습니다.
